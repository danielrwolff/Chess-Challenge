# Chess Coding Challenge (C#)

This is my entry to Sebastian Lague's "Tiny Chess Bot Challenge"! The aim of the competition was to develop the best chess bot with the least amount of C# "tokens". **I managed to rank 16th out of over 600 contestants!**

See the [Contest README](./CONTEST_README.md) for more information on how the contest worked and the results.
